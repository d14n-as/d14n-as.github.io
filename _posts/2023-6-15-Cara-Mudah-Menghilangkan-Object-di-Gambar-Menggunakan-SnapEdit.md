## Apa itu SnapEdit?

Sebuah situs web terintegrasi dengan sistem AI (Artificial Intelligence) yang mampu menghilangkan objek di foto dengan mudah tanpa ribet. Bukan hanya itu, hingga tulisan ini dibuat, SnapEdit juga mampu menghilangkan latar belakang foto, meningkatkan kualitas foto, dan menjadikan foto lama terlihat lebih jelas.

Sesuai judulnya, kali ini saya akan membahas tentang cara mudah menghilangkan objek pada foto menggunakan SnapEdit.

## Menggunakan Cara Manual (Brush)

- Klik "Upload Image"

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-1.jpg)

- Pilih image yang akan dihilangkan objeknya. Lalu klik Open
- Kemudian tampilannya akan seperti di bawah ini

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-2.jpg)

- Lalu seleksi objek (gerakan mouse ke objek yang akan dihilangkan)

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-3.jpg)

- Setelah selesai, klik "Remove"

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-4.jpg)

- Tunggu sebentar...

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-5.jpg)

- Jika masih ada yang belum sesuai, seleksi kembali dengan mouse, kemudian klik "Remove"

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-6.jpg)

- Dan hasilnya...

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-7.jpg)

- Klik "Download HD" untuk mengunduh

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-8.jpg)

## Menggunakan AI (Artificial Intelligence)

- Klik "Upload Image"

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-1.jpg)

- Pilih image yang akan dihilangkan objeknya. Lalu klik Open
- Kemudian tampilannya akan seperti di bawah ini

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-2.jpg)

- Klik pada "Auto AI" 

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-9.jpg)

- Lalu secara otomatis AI akan menyarankan beberapa objek yang akan dihilangkan

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-10.jpg)

- Karena saya akan menghilangkan objek person di dalam image tersebut, maka saya pilih person

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-11.jpg)

- Kemudian klik "Remove"

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-12.jpg)

- Maka hasilnya seperti berikut

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-13.jpg)

- Klik "Download HD" untuk mengunduh

![Cara Mudah Menghilangkan Object di Gambar]({{ site.baseurl }}/images/snapedit-14.jpg)
