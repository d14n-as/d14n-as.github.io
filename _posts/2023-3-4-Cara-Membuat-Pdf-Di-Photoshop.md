## Langkah-langkah membuat PDF di Photoshop

Terkadang saya masih suka bingung membuat PDF. Banyak sekali cara sebetulnya, apalagi ditengah gempuran AI dewasa ini. Karena pekerjaan saya menggunakan Adobe Photoshop, maka tidak ada salahnya saya membagikan cara membuat pdf kali ini.

Berikut caranya:
- Buka aplikasi Adobe Photoshop
- Klik pada File
- Arahkan mouse pada Automate

![Cara Membuat PDF]({{ site.baseurl }}/images/pdf.jpg)

- Kemudian pilih dan klik pada PDF Presentation

![Cara Membuat PDF]({{ site.baseurl }}/images/pdf-2.jpg)

- Lalu klik pada Browse untuk menambahkan file yang akan dibuat ke PDF
- Tambahkan sebanyak yang Anda perlu
- Kemudian klik Save di pojok kanan atas
- Kemudian silakan tentukan direktori penyimpanannya, dan klik Save
- Jika muncul kembali pop up, silakan klik save pdf
