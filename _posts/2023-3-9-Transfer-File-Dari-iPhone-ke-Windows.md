## Fitur-fitur Intel Unison

Dewasa ini, perkembangan sistem informasi teknologi semakin pesat. Sebelum tahu ada aplikasi bernama Intel Unison, saya seringkali kebingungan mencari aplikasi serupa untuk mengirim file atau data dari ponsel ke perangkat komputer lainnya (iOS atau Android). 

Disadur dari https://www.intel.co.id/content/www/id/id/products/docs/unison/overview.html Berikut beberapa fitur Intel Unison:
- Memudahkan transfer file/data dari perangkat iOS ke windows maupun sebaliknya
- Membuat dan menerima panggilan dari PC
- Mengirim dan menerima pesan dari PC 
- Menerima pemberitahuan secara real time

## Langkah-langkah menginstall aplikasi Intel Unison 

Berikut caranya:
- Pengguna ponsel iPhone, bisa langsung download di appstore, kemudian silakan melakukan instalasi seperti biasanya
- Jika Intel Unison sudah terinstall di ponsel, jangan lupa untuk menyalakan bluetooth 
- Pengguna PC Windows, bisa download di sini https://apps.microsoft.com/store/detail/intel%C2%AE-unison%E2%84%A2/9PP9GZM2GN26
- Kemudian klik "Get In Store app"

![Cara Install Intel Unison]({{ site.baseurl }}/images/how-to-1.jpg)

- Jika ada pop up muncul, silakan klik "Open Microsoft Store"
- Lalu klik "Get"

![Cara Install Intel Unison]({{ site.baseurl }}/images/unison.jpg)

- Kemudian tunggu proses install/download nya

![Cara Install Intel Unison]({{ site.baseurl }}/images/how-to-2.jpg)

- Setelah proses instalasi selesai klik "Open"

![Cara Install Intel Unison]({{ site.baseurl }}/images/how-to-3.jpg)

- Selanjutnya silakan hubungkan, dengan scan QR code menggunakan aplikasi intel unison yang sudah terinstall di ponsel

![Cara Install Intel Unison]({{ site.baseurl }}/images/how-to-4.jpg)

- Tunggu sampai prosesnya selesai

![Cara Install Intel Unison]({{ site.baseurl }}/images/how-to-5.jpg)

- Jangan lupa untuk mengaktifkan pemberitahuan pada device dari PC Anda, jika bluetooth sudah terhubung ke ponsel

![Cara Install Intel Unison]({{ site.baseurl }}/images/bluetooth.jpg)

- Jika sudah selesai, maka tampilan di PC Windows seperti ini
