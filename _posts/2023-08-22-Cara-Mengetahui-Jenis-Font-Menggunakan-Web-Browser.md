## Apa itu google extention?

Google Extension (atau sering disebut juga sebagai Google Chrome Extension) adalah program tambahan kecil yang dapat diinstal di peramban web Google Chrome untuk menambahkan fungsionalitas tertentu ke peramban tersebut. Ekstensi ini dapat mengubah atau memperluas cara Kamu berinteraksi dengan peramban, memberikan fitur tambahan, dan meningkatkan produktivitas.

## Contoh penggunaan Google Extension meliputi

Adblockers: Ekstensi ini memungkinkan Kamu untuk memblokir iklan yang muncul saat menjelajah web, meningkatkan pengalaman browsing Kamu.

Grammar Checkers: Beberapa ekstensi membantu Kamu dalam memeriksa tata bahasa dan ejaan saat menulis di berbagai situs web.

Password Managers: Ekstensi ini membantu Kamu menyimpan dan mengelola kata sandi dengan aman.

Productivity Tools: Terdapat berbagai ekstensi yang membantu meningkatkan produktivitas, seperti pengelola tugas, pengingat, dan alat untuk mengatur waktu.

Web Page Screenshot Tools: Kamu bisa menggunakan ekstensi untuk dengan mudah mengambil tangkapan layar dari seluruh halaman web atau bagian tertentu.

Translator Extensions: Ekstensi ini dapat menerjemahkan teks atau halaman web ke berbagai bahasa.

Social Media Tools: Terdapat ekstensi yang memungkinkan Kamu dengan cepat berbagi konten ke platform media sosial atau mengakses notifikasi media sosial.

News and Content Aggregators: Beberapa ekstensi membantu Kamu mengatur dan mengakses berita atau konten online yang menarik minat Kamu.

Beberapa Web Developer dan Web Designer, pasti tidak asing lagi dalam menggunakan tool google extention: WhatFont. Salah satu tool yang membantu Web Developer dan Web Designer bekerja.

## Cara Memasang WhatFont di Google Chrome

- Googling "whatfont google extension"
- Kemudian silakan klik yang paling atas

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-1.jpg)

- Selanjutnya akan masuk ke halaman Official Chrome Web Store

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-2.jpg)

- Silakan klik "Tambahkan ke Chrome"
- Kemudian klik "Add Extention"

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-3.jpg)

- Berhasil ditambahkan ke Google Chrome

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-4.jpg)

- Untuk menggunakannya, silakan klik icon WhatFont pada address bar di pojok kanan atas

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-5.jpg)

- Lalu arahkan kursor pada font yang ingin kita tahu jenisnya apa, contoh di bawah ini font tersebut menggunakan Arial.

![Cara Mengetahui Jenis Font Menggunakan Web Browser]({{ site.baseurl }}/images/what-font-6.jpg)
